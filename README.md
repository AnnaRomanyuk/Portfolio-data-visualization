# Привет!

Ты попал в моё портфолио по визуализации данных. Здесь мои учебные и пет-проекты, где я практикую построение дашбордов и визуализацию данных. 

Каждая папка - один проект. Внутри - файл дашборда (.pbix / .twbx), скриншот в jpg для быстрого просмотра, а также подготовленные данные. \
Дашборды построены на основе синтетических данных и данных, взятых из открытых источников (Kaggle, открытые данные). \
Стек:
 - BI-инструменты: Power BI, Tableau, Yandex DataLens
 - Подготовка данных: SQL, MS Excel, Python (pandas, numpy)
 - Навыки: моделирование данных, DAX/расчёты, дизайн дашбордов
